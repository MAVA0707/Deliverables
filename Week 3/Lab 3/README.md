---

## 📋 Overview

This lab builds a creative AI agent that handles "complaints" about inconsistencies in the **Normal Objects** universe using **LangChain's flexible tool-calling framework**. The agent (Becma) has access to four themed tools which it chains freely — in any order — to produce entertaining, themed resolutions to each complaint.

This is **Lab 1** of the NormalObjects project. Lab 2 (Thursday) implements the same concept using **LangGraph** with strict, deterministic workflows.

## ▶️ How to Run

### Option A — Python script

```bash
python normalobjects_langchain.py
```

The script processes all four sample complaints end-to-end and prints a tool-usage analysis at the end. No arguments needed.

### Option B — Jupyter notebook

```bash
jupyter notebook normalobjects_langchain.ipynb
# or
jupyter lab normalobjects_langchain.ipynb
```

Run cells **top to bottom** (Kernel → Restart & Run All). Each step is self-contained with markdown explanations. The final cell writes `lab_summary.md` to disk automatically.

## 📝 Pitfalls (LangChain freeform vs. LangGraph structured)

| Concern | LangChain (this lab) | LangGraph (Lab 2) |
|---|---|---|
| Tool order | Non-deterministic — agent decides each run | Explicit edges define the path |
| Loops | Possible; guarded by `max_iterations=6` | Prevented by graph structure |
| Debugging | Requires callback instrumentation | Node-level state is inspectable |
| Best for | Open-ended, creative, exploratory tasks | Business logic, auditability, strict flows |
