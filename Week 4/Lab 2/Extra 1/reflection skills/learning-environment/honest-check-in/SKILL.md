# Honest Check-In

Use this skill to turn friction into a useful, non-judgmental report.

## Procedure

1. Describe the symptom in plain language.
2. Summarize what was tried in chronological order.
3. State what was learned, even if the result is incomplete.
4. End with one concrete next question or help request.
5. Distinguish panic from productive confusion.

## Output Shape

Prefer this format:

- `What happened`: the visible symptom, error, or confusion
- `What I tried`: concise chronological actions already taken
- `What I learned`: the useful takeaway so far, even if partial
- `What I need next`: one specific question for a peer, mentor, or forum

## Rules

- Keep the report calm, direct, and self-compassionate.
- Do not frame the user as failing; frame the issue as information.
- Do not invent a diagnosis when the cause is unclear.
- If the next step is unclear, ask for the smallest missing detail that would unblock progress.
