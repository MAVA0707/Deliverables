# Lab Summary

The most useful nodes day-to-day are **Webhook** and **Form Trigger** (entry points for HTTP and file-upload flows), **HTTP Request** (talk to any API), **Set** (reshape fields before passing data on), **IF/Switch** (route based on logic), and **Code** (escape hatch for anything the other nodes can't express cleanly); for AI pipelines, the essential set is **Document Loader → Text Splitter → OpenAI Embeddings → Pinecone Vector Store** for ingestion, and **Chat Trigger → RAG Agent → Retrieve from Pinecone → Cohere Reranker** for retrieval. Pick a node by matching its category to your need: use a Trigger to start, Integration nodes to move data in/out of external services, Transform nodes to reshape it, Logic nodes to branch, and RAG/Vector nodes when the task involves storing or searching document knowledge—only reach for Code when a simpler node won't do the job. For debugging, open the execution view and click the node that produced wrong output; the input and output panels show the exact JSON at that step, so you can pinpoint whether the problem is upstream data or the node's own configuration—one RAG-specific tip: if retrieval returns irrelevant chunks, check that the insert and retrieve embedding models use identical dimensions (both must be 512, or both 1536), since a mismatch silently corrupts similarity scores. See the [Node Reference Table](n8n_Lab.md#node-reference-table) and [RAG Workflow section](n8n_Lab.md#rag-workflow--document-upload-chatbot-with-cohere-reranking) in `n8n_Lab.md` for field-level detail.
