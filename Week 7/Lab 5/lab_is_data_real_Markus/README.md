# Dark Data Extraction Lab

Transform 81 unstructured customer support tickets into a structured dataset
ready for Tableau / Power BI using an OpenAI + LangSmith pipeline.

## Repository map

```
├── 02_lab_data_enhancing.ipynb   ← Main extraction pipeline (all TODOs)
├── support_tickets.csv           ← Raw unstructured input (81 tickets)
├── support_tickets_labeled.csv   ← Ground-truth labels (for calibration)
├── tickets_structured.csv        ← Final structured output (deliverable)
├── lab_summary.md                ← One-paragraph reflection (calibration + next steps)
└── README.md                     ← This file
```

## How to run

### 1. Install dependencies

```bash
pip install openai langsmith python-dotenv pandas
```

### 2. Set environment variables

Create a `.env` file in this directory:

```
OPENAI_API_KEY=<your key from platform.openai.com>
LANGSMITH_API_KEY=<your key from smith.langchain.com>
```

### 3. Run the notebook

```bash
jupyter notebook 02_lab_data_enhancing.ipynb
```

Execute cells top to bottom. LangSmith traces will appear under the project
`dark-data-lab` at https://eu.api.smith.langchain.com.

### 4. Output

`tickets_structured.csv` is generated by TODO 7 and contains:

| Column | Description |
|---|---|
| `ticket_id` | Original ID |
| `submitted_at` | Date submitted |
| `month` | YYYY-MM (for trend charts) |
| `category` | billing / technical / feature_request / praise / other |
| `sentiment` | positive / neutral / negative |
| `urgency` | high / medium / low |
| `confidence` | high / low |
| `needs_review` | True if confidence=low or parse error |
| `topic` | One-sentence LLM summary |
| `raw_text` | Original ticket text |
